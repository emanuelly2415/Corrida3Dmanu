# 🏎️ Corrida 3D

### Uma corrida emocionante pelas ruas da cidade!

O **Corrida 3D** é um jogo de corrida de carros, desenvolvido com HTML, CSS e JavaScript.

O jogo permite que dois jogadores disputem uma corrida em uma cidade com pista infinita, carros esportivos e desafios durante o percurso.

## 🎮 Sobre o jogo

- Corrida para dois jogadores.
- Carros esportivos inspirados em Ferraris.
- Cidade em ambiente 3D.
- Pista infinita.
- Sistema de velocidade e distância.
- Colisões entre os veículos.
- Sistema de vitória.
- Controles para computador e celular.

## 🕹️ Controles

**Jogador 1**
- W: Acelerar
- S: Frear
- A: Virar para esquerda
- D: Virar para direita

**Jogador 2**
- ↑: Acelerar
- ↓: Frear
- ←: Virar para esquerda
- →: Virar para direita

**Celular:** controles por botões na tela para os dois jogadores.

## 🛠️ Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- Three.js
- WebGL

## 🏁 Objetivo

O objetivo é disputar uma corrida entre dois jogadores, controlar seu carro, evitar colisões e chegar primeiro à linha de chegada.

## 👩‍💻 Desenvolvimento

Projeto desenvolvido como atividade de aprendizagem, utilizando programação e inteligência artificial como apoio na criação e melhoria do jogo.
