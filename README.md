# 🏎️ City Racing 3D

Um jogo de corrida em 3D para dois jogadores, desenvolvido com **HTML, CSS, JavaScript e Three.js**.

## 🎮 Sobre o jogo

O City Racing 3D coloca dois jogadores para competir em uma cidade 3D. Cada jogador controla seu próprio carro, acelera, freia e desvia para tentar chegar primeiro ao final da corrida.

## 🕹️ Controles

### Computador
| Ação | Jogador 1 | Jogador 2 |
|---|---|---|
| Acelerar | W | ↑ |
| Frear | S | ↓ |
| Virar à esquerda | A | ← |
| Virar à direita | D | → |

### Celular
- O jogo possui botões de toque separados para cada jogador.
- Jogador 1 usa os controles vermelhos.
- Jogador 2 usa os controles azuis.
- Para ter mais espaço para os dois jogadores, recomenda-se usar o celular na horizontal.

## 🧰 Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript (módulos ES)
- [Three.js](https://threejs.org/) para a cena e os gráficos 3D
- [GLTFLoader](https://threejs.org/docs/#examples/en/loaders/GLTFLoader) para carregar o modelo 3D do carro

## ▶️ Como executar

1. Baixe ou clone este repositório.
2. Abra a pasta do projeto no Visual Studio Code.
3. Execute o arquivo `index.html` com uma extensão de servidor local, como **Live Server**.
4. Aguarde o carregamento da cena e dos modelos 3D.
5. Clique em **Começar corrida**.

> O jogo utiliza bibliotecas e modelos carregados pela internet. Por isso, é necessário estar conectado à internet durante a execução.
